# doorcam32 viewer - companion display for doorcam32 project

## what's this project?
this is a project to go along the [doorcam32 project]() i made  
and the project is based on the waveshare esp32s3 smart 86 box, lvgl and nothing else

## what do i need for this project?
if u want to make this, you're gonna need:
* parts for the doorcam32 project
* waveshare esp32s3 smart 86 box ([wiki](https://www.waveshare.com/wiki/ESP32-S3-Touch-LCD-4B?srsltid=AYCX9vJ5t3haedXkLhSMmaRC-f_z7sigwTgRgxt0obJ001iQXLc3w9x9) | [product](https://www.waveshare.com/esp32-s3-touch-lcd-4b.htm))
* a rubber duck (yes, you need one)
